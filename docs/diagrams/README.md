# Editable Mermaid diagrams

- `approval-flow.mmd`: current control flow with purple change emphasis.
- `review-sequence.mmd`: per-request timing, original fallback and final enforcement.
- `deployment.mmd`: trusted host, optional localhost service, untrusted workspace and external API.

The principal diagram is embedded in `../../ARCHITECTURE.md`. These are Mermaid source files, not screenshots or machine-rendered PNGs. Open them in a Mermaid-compatible renderer or use your team's existing Mermaid export tool. No external diagram-rendering service is needed to inspect or version the source.
